# Phishing / Spam SMS Classifier

A machine-learning classifier that flags spam and phishing-style ("smishing")
SMS messages, built with **TF-IDF feature extraction** and a **Multinomial
Naive Bayes** model. Trained and evaluated on the public UCI SMS Spam
Collection (5,572 labelled messages).

The goal: show the core technique behind an automated spam/phishing filter —
turning raw message text into features a model can score, then measuring how
well it separates malicious messages from legitimate ones.
